# Agent loop

Edit the screen, then run `npm run shots`. Open the PNGs in `shots/` beside `instructions/we-rankin-style-specimen.html`. Check `docs/style-checklist.md`. Repeat. Stop after 5 passes or when every item is green.

Compare UI shots to the specimen. Do not compare them to Style Guide v0.

Commit screenshot baselines only after the host approves them. Later diffs use Playwright `toHaveScreenshot`.
